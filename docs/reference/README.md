# API Reference Index

This directory will hold researched integration references for Discord (ingestion), Slack (notifications), the scheduler, and the chosen LLM provider. Phase 0 tasks populate these files with links, scopes, rate limits, and example payloads.

Files:
- `discord.md` — gateway/intents, relevant REST endpoints, rate limits, permalinks.
- `slack.md` — Web API (`chat.postMessage`), Block Kit, channel IDs, limits.
- `llm.md` — provider/models, JSON output mode, rate limits, cost.
- `scheduler.md` — 5:00 AM PT cron and DST considerations.

Populate these with official doc links and concise notes, then keep up to date as integrations change.
